# AI System Description

Status: `NO_AI`

Access Layer has no repository-observed AI system. It uses deterministic Fastify application logic, Google identity validation, PostgreSQL authorization/session state and RS256 JWT issuance. There are no AI providers, models or AI use cases registered in `specs/ai-providers.v1.yml` or `specs/ai-use-cases.v1.yml`.

The service does process personal identity and authorization data. That fact does not make it an AI system. Those data remain governed by the existing security, privacy and audit rules. Any future AI proposal is blocked by default until separately approved.
